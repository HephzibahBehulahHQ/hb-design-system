# Instructions for AI coding agents

This repository is the canonical Hephzibah Behulah design system for all five divisions. Read `README.md`, `tokens/corporate.json`, `tokens/brands.json` and `templates/universal-product/README.md` before modifying a product.

Mandatory product requirements: three-level corporate/division/product identity; approved logos and responsive header/footer; English, German, Yoruba and Nigerian Pidgin localization; accessible theme controls; a floating Adigun BOT interface that is product-aware and supports only validated product-specific actions. Do not claim a UI mockup or config constitutes a functioning bot or completed translation.

Preserve existing product features, storage formats and deployments. Never invent brand assets, APIs or functional buttons. Use a separate branch and verify tests before merging. For circuit generation, require a validated native canvas import adapter, preview, explicit confirmation and undo support. Keep AI secrets on the server. Report Done / Tested / Next accurately.
