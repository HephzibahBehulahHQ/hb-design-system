# Adigun BOT component agent guidance

Read the component README and the four focused standards before modifying this component contract.

- Keep the floating UI non-modal on desktop unless a small-screen presentation requires otherwise.
- Do not claim product tools, live state, AI backends, Cloudflare, Supabase or persistence work without product-specific evidence.
- Product adapters must expose only registered, schema-validated, authorized tools with preview, confirmation and undo where supported.
- Preserve the reusable contract; domain capabilities belong in the corresponding product adapter.
- Follow the global policy for security, testing, approvals, source control and reporting.
