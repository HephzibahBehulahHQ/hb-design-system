# Adigun BOT component standard

The Adigun BOT foundation is a reusable floating, product-aware copilot interface. It is not a promise that every product already has a deployed AI service, live context, tool integration or cloud persistence.

## Ownership

The design system owns reusable interface and integration standards. Each product owns its domain adapter, actual application-state APIs, tool implementations, schemas, permissions, product tests and deployment. Global agent behavior, approvals and security policy remain canonical in [hb-AI-policy](https://github.com/HephzibahBehulahHQ/hb-AI-policy).
